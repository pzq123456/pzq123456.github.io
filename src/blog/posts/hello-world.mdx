## 为什么是 MDX

Markdown 适合写作，React 适合演示。MDX 把两者放在同一个文件里：

- 标题、段落和列表交给 Markdown；
- 需要交互时，直接 `import` 一个普通组件；
- 主题、语言和已有依赖都可以继续复用。

> 博客不该成为另一个需要维护的产品。它应该只是网站的一间侧房。

## 写作约定

文章的标题、日期和摘要放在 `src/blog/posts.ts`，正文从普通段落开始，不需要再写一次一级标题。代码块、引用和列表会沿用网站已有的字体与颜色。

代码块支持文件名标题、行号和行高亮：

```tsx title="ExampleDemo.tsx" showLineNumbers {3}
import ExampleDemo from "../demos/ExampleDemo";

<ExampleDemo />
```

如果要加图片，把文件放到 `public/blog/`，然后在 MDX 里使用普通 Markdown 图片语法；深色模式、窄屏和图片宽度都会继承正文样式。更多语法可以参考 [MDX 文档](https://mdxjs.com/)。
